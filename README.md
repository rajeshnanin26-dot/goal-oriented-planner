# 🎯 Goal-Oriented Planner Using Python

## 📌 About the Project
The Goal-Oriented Planner is a Python-based application designed to help users set goals, organize tasks, manage deadlines, and track their progress. It uses an SQLite database to store information permanently.

## ✨ Features
- Create and manage goals.
- Add multiple tasks under each goal.
- Set deadlines for goals and tasks.
- Mark tasks as completed.
- Update goal status.
- View upcoming and overdue tasks.
- Track goal and task completion percentages.
- Store data using SQLite.

## 🛠️ Technologies Used
- Python
- SQLite
- SQL
- datetime module


**Step 3: Run the application**
